# Portfolio presentation plan

Goal: make the private GitHub portfolio easy for a recruiter to scan.

Design: a navy and teal SVG masthead, actual application screenshots, concise project stories and a compact extension table. Use standard GitHub Markdown. Feature Job Compass and Build Lab; preserve Blender work and every selected project. Label sample data and avoid invented metrics or sole-authorship claims.

Implementation: add header and Job Compass screenshot; rewrite the landing README; add return navigation to project READMEs. Preserve setup instructions, attribution and limitations.

Validation: inspect rendered assets, check relative links and SVG XML, inspect the documentation-only diff, then commit and push. No application behavior changes or CV edits are in scope.
