# Automatic preparation queue

Use the existing automatic-check switch to prepare up to five new, strong development matches per cycle. Reassess against the current profile; require score 80+, confirmed geography, matching skills and no gaps or flags. Require the English developer CV. English is the initial draft language; the existing reviewer can choose Portuguese and regenerate.

Only untouched new jobs qualify. Conditional updates protect edits, saved jobs and concurrent status changes. The result is a draft in the existing review queue, never an approval or submission. Existing answer confirmation and approval snapshots remain authoritative.

Tests cover selection, pause, missing CV, repeat runs, preserved edits and batch limits. Run the API suite and isolated application workflow before restarting the local service.
